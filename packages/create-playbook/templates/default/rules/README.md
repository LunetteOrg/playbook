# Rules

One file per rule, `RULE-<n>-<topic>.md`. The header carries `code`, `status`,
`applies` and the links; the title is the rule itself, as an obligation or a
prohibition, followed by `## Why` and, when there are any, `## Exceptions`.

`applies: everywhere` means the rule holds in any work; `applies: where-cited`
means it holds where a process or a procedure lists it in `rules`.
